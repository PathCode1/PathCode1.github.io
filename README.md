# PathCode

Сайт-визитка: сайты, Telegram-боты, парсеры и интеграции.

- `index.html` — главная страница (собирается из `page.html` командой `python build.py`).
- `works/` — пять демо-сайтов: кафе, стоматология, студия красоты, автосервис, цветы.
- `img/app-*.webp` — концепты пяти Android-приложений для вкладки «Приложения»: обложка и три экрана.
- `works/apps/` — пять рабочих демо-приложений (запись в салон, доставка еды, фитнес-клуб, учёт финансов, онлайн-школа). Общий движок `kit.js` и стили `kit.css`; данные хранятся в localStorage браузера. При правке `kit.*` поднимите `?v=` в подключениях.
- `img/` — фото для демо. Авторы и лицензии перечислены в `img/credits.json` и в подвале каждого демо-сайта.
