# PathCode

Сайт-визитка: сайты, Telegram-боты, парсеры и интеграции.

- `index.html` — главная страница (собирается из `page.html` командой `python build.py`).
- `works/` — пять демо-сайтов: кафе, стоматология, студия красоты, автосервис, цветы.
- `img/` — фото для демо. Авторы и лицензии перечислены в `img/credits.json` и в подвале каждого демо-сайта.

Связь: Telegram [@BeauG0sse](https://t.me/BeauG0sse), [Kwork](https://kwork.ru/user/pathcode).
